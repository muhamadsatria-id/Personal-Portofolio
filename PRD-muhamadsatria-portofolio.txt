3. TECH STACK (WAJIB)
--------------------------------------------------------------------------------
Backend    : Laravel (versi terbaru yang terpasang di project), PHP 8.3+
Frontend   : React + TypeScript via Inertia.js (Laravel React Starter Kit
             yang SUDAH terpasang di project - gunakan, jangan buat ulang)
UI         : Tailwind CSS v4 + shadcn/ui (starter kit sudah memakai ini)
Animasi    : Motion (paket "motion", dulu framer-motion) untuk transisi,
             scroll-reveal, stagger; opsional Lenis untuk smooth scroll
Database   : MySQL (production), SQLite boleh untuk testing lokal
Auth       : Laravel Fortify / auth bawaan starter kit (login, 2FA opsional)
Rich text  : TipTap (editor blog dan deskripsi proyek) - output HTML bersih
             yang di-sanitize di server
Upload     : Laravel Storage (disk public) + intervention/image untuk resize
             dan konversi WebP
SEO        : Server-side rendering meta tag lewat Inertia <Head> dan Blade
             layout; sitemap.xml dan robots.txt dinamis
Queue/Cache: database queue + cache (file/database) - tidak wajib Redis
Test       : Pest (PHP) + minimal smoke test untuk halaman utama & admin
Deploy     : VPS Ubuntu (aaPanel) / Cloudflare Tunnel; sediakan .env.example
             dan panduan singkat di README

PENTING SEO: Karena memakai Inertia + React, aktifkan SSR Inertia
(`npm run build:ssr` / php artisan inertia:start-ssr) agar konten ter-render di
HTML awal untuk crawler. Jika SSR belum memungkinkan di server, minimal pastikan
<title>, meta description, canonical, Open Graph, dan JSON-LD dirender di sisi
server lewat Blade layout (app.blade.php) dengan data dari controller.

BENAR (versi mentah dari generator memakai prefix --color-* untuk semua token,
termasuk radius/font/spacing/shadow, ini SALAH untuk non-warna). Gunakan:

    /* warna: --color-<nama>: var(--<nama>) untuk
       background, foreground, card, card-foreground, popover,
       popover-foreground, primary, primary-foreground, secondary,
       secondary-foreground, muted, muted-foreground, accent,
       accent-foreground, destructive, destructive-foreground, border,
       input, ring, chart-1..5, sidebar, sidebar-foreground,
       sidebar-primary, sidebar-primary-foreground, sidebar-accent,
       sidebar-accent-foreground, sidebar-border, sidebar-ring */

    --radius-md: var(--radius);
    --radius-lg: calc(var(--radius) + 2px);
    --radius-xl: calc(var(--radius) + 6px);
    --font-sans: var(--font-sans);
    --font-serif: var(--font-serif);
    --font-mono: var(--font-mono);
  }

Tipografi:
  - Sans (UI/body): Antic (Google Fonts), fallback system-ui. Self-host atau
    gunakan <link rel="preconnect"> + font-display: swap.
  - Serif (heading/aksen editorial): "Signifier" adalah font komersial;
    JANGAN dipakai kecuali ada lisensi. Gunakan fallback Georgia (sudah ada di
    token) atau ganti dengan font serif gratis (mis. Fraunces / Newsreader).
  - Mono: JetBrains Mono (untuk label teknis, badge tech stack, kode).
  - Skala heading: H1 serif besar (clamp 2.5rem-4.5rem), H2 serif, body sans.

Gaya visual (acuan dari halaman projects.html yang sudah ada):
  - Layout editorial: garis pemisah tipis (border), banyak whitespace, kartu
    datar dengan shadow sangat halus (token --shadow-*), sudut kecil (radius
    0.35rem).
  - Daftar proyek gaya "accordion per tahun" (seperti projects.html) dipakai
    sebagai salah satu mode tampilan di halaman Projects (lihat 6.3).
  - Header sticky dengan backdrop-blur, tombol CTA "Contact" bulat (primary).
  - Warna aksen utama = --primary (#0c4b29 terang / #70a84d gelap); permukaan
    sekunder = --secondary / --accent (sage).
  - Catatan: projects.html lama memakai emerald Tailwind; untuk versi baru
    gunakan token di atas (sage/forest), bukan kelas emerald-*.

Aksesibilitas: kontras WCAG AA, focus ring terlihat (--ring), semantic HTML,
alt text gambar wajib (field di admin), skip-to-content link, navigasi keyboard.

--------------------------------------------------------------------------------
Buat halaman error kustom (React/Inertia, memakai layout publik dan tema):
  - 404 Not Found   : ilustrasi/angka "404" beranimasi halus, pesan ramah,
                      kotak pencarian proyek/blog, tombol "Kembali ke Beranda",
                      daftar link populer (Projects, Blog, Contact).
  - 403 Forbidden   : akses ditolak.
  - 419 Page Expired: sesi kedaluwarsa, tombol muat ulang.
  - 429 Too Many Requests: terlalu banyak permintaan.
  - 500 / 503       : kesalahan server / maintenance, tanpa membocorkan detail.
Persyaratan:
  - Respons memakai status HTTP yang benar (404 tetap 404, bukan 200).
  - <meta name="robots" content="noindex"> pada halaman error.
  - Tangani via bootstrap/app.php (withExceptions) untuk merender komponen
    Inertia "Errors/{status}"; untuk request JSON/API tetap kembalikan JSON.
  - Error di area /admin memakai tampilan error versi admin.
  - Mode Maintenance: halaman "Sedang dalam pemeliharaan" kustom, dapat
    diaktifkan dari admin (toggle), admin tetap bisa login.
  - Catat 404 yang sering terjadi ke tabel `redirects_404_log` (path, hits,
    last_seen) untuk dipantau dan dibuatkan redirect dari admin.

10. SCRIPT & INTEGRASI MANAGER (HEAD / BODY / FOOTER)
--------------------------------------------------------------------------------
Tujuan: admin dapat menempelkan kode pelacakan/iklan/widget tanpa mengubah
source code. Semua field OPSIONAL (kosong = tidak ada output).

10.1 Field integrasi cepat (cukup isi ID, sistem membuat snippet resmi)
  - Google Analytics 4 (Measurement ID, G-XXXXXXX)
  - Google Tag Manager (Container ID, GTM-XXXXXXX; snippet <head> + <noscript>
    di awal <body>)
  - Google AdSense (Publisher ID ca-pub-XXXXXXXX; script di head; sekaligus
    kelola file ads.txt dari admin)
  - Meta/Facebook Pixel (Pixel ID)
  - Microsoft Clarity (Project ID)
  - Cloudflare Web Analytics (token)
  - Cloudflare Turnstile (site key)
  Tiap integrasi punya toggle aktif/nonaktif.

10.2 Injeksi script kustom bebas (textarea/code editor, monospace)
  Slot injeksi:
   1. HEAD - awal (setelah <meta charset>)
   2. HEAD - akhir (sebelum </head>)
   3. BODY - awal (tepat setelah <body>)
   4. BODY - akhir / footer (sebelum </body>)
  Opsi per slot:
   - Aktif/nonaktif.
   - Cakupan: semua halaman | hanya beranda | hanya blog | hanya halaman
     tertentu (pilih dari daftar) | kecualikan halaman tertentu.
   - Lingkungan: hanya production (mencegah hit analytics saat dev).
   - Prioritas/urutan jika ada beberapa blok.
  Dapat dibuat BANYAK blok bernama (mis. "Hotjar", "Chat widget") dengan
  slot, cakupan, status, dan catatan masing-masing.

10.3 Consent & privasi
  - Opsional banner persetujuan cookie (teks dapat diedit): script kategori
    "analytics/ads" hanya dimuat setelah pengguna setuju (Consent Mode v2
    untuk Google bila diaktifkan).
  - Halaman Privacy Policy dapat diedit lewat Halaman Statis.

10.4 Keamanan fitur script (PENTING)
  - Hanya role admin yang dapat mengakses fitur ini; wajib konfirmasi
    password / sesi baru-baru ini saat menyimpan perubahan.
  - Konten script SENGAJA dirender mentah (tidak di-escape) karena memang
    kode; maka JANGAN pernah menyimpan input dari pengguna publik ke slot
    ini. Cukup tampilkan peringatan di UI: "Kode ini dieksekusi di semua
    pengunjung. Tempel hanya dari sumber tepercaya."
  - Catat setiap perubahan ke activity log (siapa, kapan, sebelum/sesudah).
  - Tombol "Matikan semua script kustom" (kill switch) untuk pemulihan cepat
    bila situs rusak oleh script bermasalah.
  - Jangan menaruh script kustom di area /admin.
  - Pratinjau: tombol "Test di halaman" membuka beranda dengan query
    ?preview_scripts=1 hanya untuk admin yang sedang login.
  - Evaluasi CSP: bila Content-Security-Policy dipakai, sediakan field daftar
    domain yang diizinkan atau gunakan nonce; dokumentasikan di README.
  - Cache hasil render snippet (cache::rememberForever, di-invalidate saat
    disimpan) agar tidak query DB tiap request.

10.5 Implementasi rendering
  - Buat komponen Blade (<x-site-scripts slot="head_start" />, dst.) di
    resources/views/app.blade.php, memuat data dari cache.
  - Untuk SPA Inertia: snippet analytics yang perlu event pageview harus
    mengirim ulang pageview saat navigasi Inertia (hook ke event
    'navigate'/router.on('navigate')) agar GA4/GTM/Pixel mencatat perpindahan
    halaman. Sediakan helper JS kecil untuk ini.

             permintaan; banner cookie bila script analytics/ads aktif.
Observability: log error Laravel; halaman 404 dipantau; (opsional) Sentry.
Backup & Operasional: perintah artisan untuk backup, README deploy ke VPS
             Ubuntu (aaPanel) + opsi Cloudflare Tunnel, supervisor untuk queue
             worker, cron untuk scheduler.
